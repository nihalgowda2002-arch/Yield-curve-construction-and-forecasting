# Yield Curve Construction & Forecasting

A self-contained Python library for **building, modelling, and forecasting the
term structure of interest rates**, and applying it to **bond and interest-rate
derivative pricing** and a **forecast-driven trading strategy**.

> **What this project demonstrates:** the full quant pipeline on one asset class
> — *curve construction → pricing & risk → dynamic factor modelling → time-series
> forecasting → systematic backtest* — with the hard numerical machinery built
> from first principles, benchmarked honestly, and reproducible with one command.

Everything runs on `numpy` / `scipy` / `pandas` / `scikit-learn` / `matplotlib`.
The harder machinery — the **Kalman filter**, **VAR**, **ARIMA**, **Dynamic
Nelson–Siegel** state-space model, and a **from-scratch LSTM** (forward pass,
back-propagation-through-time, and Adam) — is all implemented from first
principles rather than pulled from `statsmodels` / PyTorch / QuantLib. This keeps
the project transparent and dependency-light, and makes the underlying maths
explicit.

The project ships with **real U.S. Treasury par-yield data** so it runs fully
offline, and a one-command pipeline (`run_all.py`) that reproduces every figure
and result below.

## What it does

|Capability                   |Implementation                                                                                                                                                       |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|**Static curve construction**|Nelson–Siegel (NS) and Nelson–Siegel–Svensson (NSS), fit by *concentrated* least squares with `scipy.optimize`                                                       |
|**Discount/zero curve**      |Par → zero **bootstrap** (PCHIP-smoothed), then an NSS fit to the bootstrapped zeros                                                                                 |
|**Bond pricing & risk**      |Clean price, YTM, Macaulay/modified duration, convexity, DV01, full-curve DV01                                                                                       |
|**Derivatives**              |Par swap rates, swap PV, FRA rates, Black-76 caplets                                                                                                                 |
|**Dynamic factor model**     |**Dynamic Nelson–Siegel** (Diebold–Li / Diebold–Rudebusch–Aruoba): latent Level/Slope/Curvature with VAR(1) dynamics, estimated two-step and by **Kalman-filter MLE**|
|**Time-series forecasting**  |**VAR(p)**, **ARIMA(p,d,q)**, a **scikit-learn ML** forecaster, and a **from-scratch NumPy LSTM** — benchmarked against a random walk                                |
|**Forecasting the curve**    |h-step-ahead curve forecasts with uncertainty bands                                                                                                                  |
|**Trading strategy**         |Forecast-driven **duration-timing** and **2s10s steepener/flattener** backtests with Sharpe, hit-rate, and PnL vs a random-walk baseline                             |

This covers all of the techniques named in the project brief: *NSS · VAR · LSTM ·
Kalman filter · ARIMA · ML*, plus bond/derivative pricing and a trading backtest.

## Headline results

Run on the bundled real curve (latest date **2026-05-06**, 14 tenors) and a
calibrated simulator for the data-hungry pieces:

- **Static fit.** NSS fits the market curve to **3.6 bps RMSE** (max error 9.0 bps);
  NS to 4.3 bps. Both factor sets are economically interpretable
  (β₀+β₁ ≈ the short rate; β₀ ≈ the long rate).
- **Short-horizon forecasting.** Over a rolling out-of-sample test, the
  **random walk is the benchmark to beat** at the 5-day horizon (≈7.5 bps RMSE) —
  the well-known stylised fact for yields — with ARIMA and VAR close behind. The
  structural models add their value in **curve-shape** forecasting and in the
  backtest, not in beating RW on a single rate at a 1-week horizon.
- **From-scratch LSTM.** Training loss falls **1.50 → 0.34** over 45 epochs,
  confirming the hand-written BPTT + Adam implementation learns.
- **Backtest.** On a panel with genuine factor dynamics, the VAR / ML / DNS
  signals beat the random-walk baseline on both the duration-timing and 2s10s
  slope strategies (higher Sharpe and hit-rate).

## Library usage

**Load data and fit a curve**

```python
from yclib import data_loader, fitting

df  = data_loader.get_yields(source="bundled")   # or "auto" to fetch online
tau = df.columns.to_numpy()                       # maturities (years)
y   = df.iloc[-1].to_numpy()                       # latest curve (%)

nss = fitting.fit_nss(tau, y)
print(nss.rmse, nss.beta, nss.lams)                # fit quality + parameters
print(nss.curve(5.0))                              # interpolated 5y yield (%)
```

**Bootstrap a zero curve and price a bond + derivatives**

```python
from yclib.bonds import ZeroCurve, price_bond, bond_risk, par_swap_rate

zc = ZeroCurve.from_par(tau, y)                    # par CMT -> bootstrapped zeros
price = price_bond(zc, maturity=10, coupon_pct=4.0)
risk  = bond_risk(price, maturity=10, coupon_pct=4.0)   # dur, convexity, DV01
swap10 = par_swap_rate(zc, tenor=10)               # 10y par swap fixed rate (%)
```

**Dynamic Nelson–Siegel: extract factors and forecast the curve**

```python
from yclib.dns import DynamicNelsonSiegel

dns = DynamicNelsonSiegel().fit(df, method="two_step")   # or method="kalman"
factors = dns.result_.factors                       # Level / Slope / Curvature series
curve_fc = dns.forecast_curve(steps=20)             # 20-business-day-ahead curve
```

**Forecast a single series — VAR / ARIMA / ML / LSTM share one interface**

```python
from yclib.var_model import VAR
from yclib.arima import ARIMA
from yclib.ml_forecast import MLForecaster

VAR(p=1).fit(df).forecast(steps=5)                  # multivariate
ARIMA(order=(1, 1, 1)).fit(df[10.0]).forecast(steps=5)   # univariate
MLForecaster().fit(df).forecast(steps=5)            # lagged-feature ML
```

**Backtest a forecast-driven strategy**

```python
from yclib import simulate, backtest

panel = simulate.calibrate_from_real(df, n_days=1200)
table = backtest.compare_models(panel, strategy="duration",
                                models=("rw", "var", "ml", "dns"))
print(table)   # sharpe, hit_rate, total_pnl, ann_vol per model
```

## Methodology

### Nelson–Siegel / Svensson

The instantaneous **NS** yield is
`y(τ) = β₀ + β₁·[(1−e^{−λτ})/(λτ)] + β₂·[(1−e^{−λτ})/(λτ) − e^{−λτ}]`,
with β₀ the **level**, β₁ the **slope**, β₂ the **curvature**, and λ controlling
where the curvature hump sits. **Svensson (NSS)** adds a second hump
(β₃, λ₂) for extra flexibility at the long end. Because the model is *linear in
the betas given the decay λ*, fitting is done by **concentrated least squares**:
for each candidate λ the betas are solved in closed form, so the non-linear
search is only over one (NS) or two (NSS) decay parameters — a coarse grid is
refined by L-BFGS-B and a final bounded `least_squares` polish. This is fast and
robust, and avoids the local minima that plague naive joint optimisation.

### Bootstrap → discount curve

Par (constant-maturity) yields are first interpolated onto a semi-annual grid
with a shape-preserving **PCHIP** spline, then bootstrapped to discount factors
via the standard recursion
`DF(tₙ) = (1 − (c/2)·Σ_{i<n} DF(tᵢ)) / (1 + c/2)`.
An NSS curve is then fit to the bootstrapped **zero** rates to give a smooth,
arbitrage-consistent discount function for pricing — the "smoothed-bootstrap"
idea from the Nelson–Siegel curve-fitting literature.

### Dynamic Nelson–Siegel (state-space)

Following Diebold–Li and Diebold–Rudebusch–Aruoba, the three NS factors are
treated as **latent states** with VAR(1) dynamics and a linear measurement
equation (fixed λ):

- **Transition:** `xₜ = μ + Φ(xₜ₋₁ − μ) + ηₜ`
- **Measurement:** `yₜ(τ) = Λ(τ)·xₜ + εₜ`, with the rows of Λ the NS loadings.

It is estimated two ways: a robust **two-step** method (cross-sectional OLS for
the factors each day, then a VAR(1) on the factor series) and a full
**Kalman-filter maximum-likelihood** fit (likelihood via the prediction-error
decomposition). Forecasts are `E[xₜ₊ₕ] = μ + Φʰ(xₜ − μ)` mapped back through Λ.

### Forecasting models

- **Kalman filter** — generic linear-Gaussian filter + RTS smoother + log-likelihood.
- **VAR(p)** — stacked OLS with intercept, iterated h-step forecasts, residual covariance.
- **ARIMA(p,d,q)** — differencing + a conditional-sum-of-squares objective minimised with `scipy.optimize`, recursive forecasting; `auto_arima` does a small AIC grid search.
- **ML forecaster** — `scikit-learn` regressor on lagged features (a dependable, data-efficient learner).
- **LSTM** — a single-layer LSTM written from scratch in NumPy: forget/input/output gates, full **back-propagation-through-time**, and an **Adam** optimiser. Deliberately small and trained on the simulated panel, it demonstrates the mechanics end-to-end.

### Trading backtest

Forecasts drive two strategies: **duration timing** (go long/short the 10y by the
predicted direction) and a **2s10s** steepener/flattener (trade the predicted
slope change). The engine reports Sharpe, hit-rate, annualised vol, and PnL, with
the **random walk as the honest benchmark**.

## Data

- **Bundled (offline):** `data/treasury_par_yields_2026.csv` — real daily U.S.
  Treasury par yields (CMT), 87 trading days × 14 tenors (1 Mo → 30 Yr), fetched
  from the U.S. Treasury. This drives the static fit, bootstrap, pricing, factor
  model, and the short out-of-sample test.
- **Online (live):** `data_loader.get_yields(source="auto")` (or `run_all.py --online`) downloads the latest full history directly from **treasury.gov**; a
  **FRED** CSV loader (`DGS*` series, no API key) is also provided.
- **Simulator:** `simulate.calibrate_from_real` builds a calibrated Dynamic
  Nelson–Siegel data-generating process whose end-state matches the real curve,
  producing a clearly-labelled multi-year **synthetic** panel for the LSTM and
  the long backtest. It is kept conceptually separate from the real data — for
  real long-history results, use the online loader.

## Design notes

- **Why from-scratch?** Implementing the Kalman filter, VAR, ARIMA, DNS and LSTM
  directly (rather than importing them) makes the methodology explicit, keeps the
  dependency surface tiny, and is the more instructive deliverable.
- **NSS for fitting, NS for dynamics.** NSS (4 factors) gives the tightest static
  fit; the dynamic model uses 3-factor NS with a *fixed* λ so the Level/Slope/
  Curvature factors stay stable and interpretable across time — standard practice
  in the Diebold–Li literature.
- **Honest benchmarking.** Yields are close to a random walk at short horizons, so
  RW is a deliberately hard baseline. The project reports where each model does
  and does not beat it rather than cherry-picking a favourable horizon.
- **Real vs synthetic.** Real Treasury data drives all curve-construction,
  pricing, and short-horizon results; the simulator only provides long synthetic
  history for the data-hungry LSTM and the multi-year backtest, and is labelled as
  such throughout.
